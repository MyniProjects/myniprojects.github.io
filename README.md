# MyniProjects

Static portfolio for independent Android games and apps. GitHub Pages serves the site at [myniprojects.github.io](https://myniprojects.github.io/).

| Files | Purpose |
| --- | --- |
| `index.html` | Portfolio home page |
| `apps.js` | Project names, package IDs, icons and links to the corresponding privacy pages |
| `main.js`, `styles.css` | Project card interactions and shared styles |
| Individual project HTML pages | Privacy policies and terms at stable public URLs |
| `app-ads.txt`, `google77ad6bf6c0b13913.html` | Advertising and Google site verification files served from the site root |

Open `index.html` locally to preview the site. Update `apps.js` to change the displayed projects. Keep existing privacy page URLs stable when updating their content.
